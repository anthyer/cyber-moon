# Cyber Moon

Jogo de fazendinha com tematica cyberpunk. Combina coleta de recursos, ciclo de dias, combate em RPG simples e um sistema de relacionamento com NPCs. A evolucao da fazenda e travada atras de marcos de recursos acumulados pelo jogador, ligados ao avanco da historia, cujo fio condutor e a expansao da cidade sobre os campos.

## Requisitos

Godot 4.7, com o renderer GL Compatibility.

## Como abrir o projeto

Abra a pasta do repositorio pelo Project Manager do Godot e selecione `project.godot`.
